# ai-work-research：AI 工作调研 Skill

一个适用于支持 Skills 的 AI Agent 的论文调研技能。围绕用户给定的 AI、机器学习、深度学习、大模型、NLP、计算机视觉、数据挖掘等主题，检索并筛选高质量论文，按年份与重要性排序，经过两轮书目信息和代码链接核验后，生成中文 Markdown 调研报告。

它优先保证**论文质量、主题相关性和元数据准确性**，不以数量凑齐报告。

## 主要特点

- **多源检索**：组合中英文关键词、同义词、旧称与方法缩写，交叉查看官方会议/期刊页、DOI、DBLP、Semantic Scholar、arXiv、作者项目页和 GitHub，并沿参考文献与引用文献前后扩展候选池。
- **严格的质量门槛**：
  - 正式发表论文以 CCF-A 会议/期刊为主，仅保留少量高质量、与主题高度相关的 CCF-B 论文；等级以检索时最新的官方 CCF 目录核对；
  - arXiv 工作仅考虑最近 2 年内公开、主题高度相关且被引数大于 5 的论文；已有正式版本的改收正式版本；
  - 不收录 CCF-C、普通 workshop、低质量或 predatory venue，不因候选少而降低标准。
- **分类与排序**：按实际文献结构归纳大类（二级标题）和细分方向（三级标题）；每个分类内先按发表年份降序，同年再按重要性降序。
- **精选中文摘要**：只为对主题特别关键的代表性工作撰写中文摘要，用自己的话概括研究问题、核心方法、主要结果和参考价值，不照抄、不夸大。
- **两轮完整核验**：成稿后逐篇执行两轮核验——第一轮对照官方来源核对标题、完整作者、年份、venue、论文链接与代码链接；第二轮用独立来源交叉复核，重点确认代码仓库归属。
- **不伪造链接**：没有可靠论文链接的工作不收录；没有官方代码或归属无法确认时省略代码链接，不填猜测地址、搜索页或第三方仓库。
- **反馈剔除项**：报告完成后，在对话中简要列出主要被剔除的工作及原因，以及因代码无法核实而省略链接的情况。

## 输出报告格式

报告只包含调研分类和论文条目，不含总标题、总体摘要、结论、趋势分析、对比表、参考文献列表或核验记录。每个条目格式如下：

```markdown
## [大类名称]

### [细分方向名称]

- **[论文原始标题]**
  [作者1], [作者2], [作者3]
  [会议或期刊标准名称/缩写] [正式发表年份].
  [Paper](论文URL) | [Code](代码URL)
```

作者按原文顺序完整列出，不使用 “et al.” 省略。报告默认保存为 `[调研主题]调研报告.md`。

## 安装

将本仓库克隆到所用 AI Agent 的用户级 skills 目录下（所有项目可用），目录名为 `ai-work-research`：

```bash
git clone https://github.com/ZZiCai/skill.ai-work-research.git <用户级-skills目录>/ai-work-research
```

也可以只下载 `SKILL.md`，与agent对话让其安装，给它看到`SKILL.md`文件即可。不同 Agent 的 skills 目录和加载方式可能不同，请参考对应文档；安装后按要求重新加载或新开会话。

## 使用

提到“AI 工作调研”“AI 论文调研”“相关工作调研”“文献调研”“调研某方向的代表工作/顶会论文/最新论文”，或要求按 CCF-A、ICML、NeurIPS、ICLR、TPAMI 等标准整理论文与代码时，支持 Skill 自动匹配的 Agent 会自动触发。对于支持手动调用 Skills 的 Agent，也可以按其提供的语法调用，例如：

```text
/ai-work-research 调研反洗钱图学习中的候选子图构建、洗钱链路识别相关工作
```

调研主题由每次调用时提供；未给出主题时，Skill 只会询问需要调研的方向，不会自行假定。

```text

```

## 注意事项

- 被引数和 GitHub star 数只作为内部筛选与排序依据，不写入报告。
- CCF 等级、被引数等数据以检索当日的查询结果为准，不同数据源可能存在差异。
- 调研质量依赖运行环境的网络检索能力；核心书目信息无法核实的论文会被剔除，代码归属无法确认时只省略代码链接。
